# FG-TIDA R04 Contributions · Working Drafts (NOT FINAL)

> **Status: DRAFT v4 · NOT FINAL · NOT SUBMITTED.** Do not cite as agreed, ratified, or submitted.

This repository holds **working drafts** of material intended for contribution to ITU-T FG-TIDA
(Focus Group on Trust and Digital Identity for AI), consolidating "runtime verification methods
built on top of an already-issued identity anchor" into discussable English input documents.

## Read this first

1. This repository is **not a deliverable** at present; it holds process drafts. Any external citation should also state "draft, not final, not submitted".
2. Numbers, standard numbers and dates appearing in the drafts are **subject to the primary source on the day of citation**; this standards line does not warrant that paraphrases inside the drafts remain valid over time.
3. If you wish to quote any sentence from them, point to **a specific file in this repository**, not to an instant-message or email paraphrase.

## Files

- `FG-TIDA-SUPPORTER-CONTRIBUTIONS.md` — supporter positioning and contribution points (C1–C8)
- `W3C-02_R04_InsertionDraft.md` — the R04 insertion draft: the `revocation_establishment` field proposal
- `W3C-02_R04_support-package.md` — supporting materials: five worked examples, JSON Schema sketch, boundary analysis, terminology diagram
- `R04_demo_5values.html` — interactive demo: five value cards plus a mini-simulator (open directly in a browser)
- `R04_demo_5values_v2.html` — minimal validator: paste a bundle JSON, get PASS/FAIL with the reason; includes a built-in negative self-test
- `LICENSE`

**if it is not yet in a state that can be delivered, then at least it should be in a state where it can be pointed out that it is not.**
